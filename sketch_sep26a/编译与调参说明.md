## 3. 核心机制：点云轮廓匹配航向闭环校准

### 3.1 扫描-运动耦合约束（严格遵守）

| 扫描用途 | 允许车运动？ | 实现 |
|---|---|---|
| 实时护栏 / 前向护栏（`sector[secOffset].dist` 刷新） | 允许 | 行进中 `scanTick()` 只刷新 sector[]，**绝不参与匹配** |
| **轮廓匹配（ref/new）** | **必须停车静止** | 仅在 `ST_CAPREF` / `ST_CAPNEW`（已 `motorStop()`）内 `capRefTick`/`capNewTick` 快扫 |
| planTurn 选向 | 最好停车静止 | `capRefTick` 快扫完成后再 `planTurn()`，用干净数据选向 |

### 3.2 闭环转向序列（状态机）

```
DECEL (0<front<=TURN_DIST)
  → enterCapRef()：motorStop()；secOffsetOld=secOffset；state=ST_CAPREF
  → ST_CAPREF：capRefTick 静态快扫 9 档 → 写 refContour[]
               planTurn()（干净数据）→ turnStep=ringStep(secOffsetOld, planHeadIdx)
               turnStep==0 ? FORWARD（死区直行）: TURN（turnCount++ 后 motorTurn）
  → ST_TURN：motorTurn 至 TURN_MS → motorStop()；capScanIdx=0；state=ST_CAPNEW
  → ST_CAPNEW：capNewTick 静态快扫 → 写 newContour[]
               matchContour(refContour, newContour) → bestShift / matchReliable
               B3 检出？(turnStep!=0 && reliable && bestShift==0) → enterDisengage()
               否则 applyCalibration() → state=ST_VERIFY
  → ST_VERIFY：front>=FREESPACE ? turnCount=0;FORWARD
               : turnCount>=MAXTURN ? BACKUP/DISENGAGE
               : enterCapRef()（刷新 refContour+secOffsetOld 重选向）
```

### 3.3 轮廓匹配（matchContour，全整数）

- 对候选滑移 `s` 在 0..11 滑动，对每个物理扇区对 `(r,c)` 求绝对距离差累加；
  `r==0||c==0`（空/盲区/开阔）的对跳过，不贡献误差也不计入 pairs（防误匹配）。
- 保留"误差最小、同误差取对多者"的峰，并顺带维护前二小峰 `(bestE, secondE)`。
- `bestShift` 符号化为 -6..+6（最短环向）。
- 可靠度三条件：
  1. `matchPairs >= MATCH_MIN_PAIRS(5)`（信息量足够，空旷回退）
  2. `bestScore <= pairs * MATCH_MAX_PAIR_DIFF(3)`（每对平均差 ≤3cm，轮廓确吻合）
  3. `secondE - bestE >= MATCH_MARGIN(2)`（峰尖锐，排除对称/平谷）

### 3.4 闭环校正（applyCalibration，防漂移）

```cpp
if (matchReliable) {
  secOffset = (secOffsetOld + bestShift + SECTOR_N) % SECTOR_N;   // 实测重建，闭环
} else {
  secOffset = (secOffsetOld + turnStep + SECTOR_N) % SECTOR_N;    // 不可信回退开环
}
```

> **关键**：不用"只补误差" `secOffset += (bestShift - turnStep)`（会累积漂移），
> 而是直接用实测 `bestShift` **重建** secOffset，保证闭环不漂移。

## 4. 三类卡死修复

### B1：前方空却转向（决策层）

- `loop()` DECEL：仅在 `front > 0 && front <= TURN_DIST` 才 `enterCapRef()` 转向；
  `front==0`（未知/盲区）或 `front>TURN_DIST`（开阔）**不转**。
- `planTurn()` 死区：`front == 0 || front >= TURN_DIST` → 直接直行不转。
- 修复了"`dist==0` 被当成有障碍触发转向"的误判。

### B2：全方向堵死无限转 + 舵机盲区

- `planTurn()` 候选扇区：`d == 0`（未知/盲区）**绝不选**为可通行目标；
  舵机只到 rel=±80°（round(±80/15)=±5）写不到 `secOffset±6` 两扇区，盲区被 `d==0` 排除。
- `planTurn()` 遍历后 `best < 0`（全堵死）→ `enterDisengage()` **兜底脱离**，
  替代原 `bdir=(secOffset+1)` 无限试探。

### B3：物理卡住转不动（轮廓匹配检出，最关键）

- `capNewTick` 匹配完成后：`commanded turnStep != 0` 且匹配**可信**且 `bestShift == 0`
  → 判定"轮子在转、车身被夹/打滑没转" → `enterDisengage()` 立即倒车脱离。
- 与"空旷不可信"严格区分：B3 要求 `matchReliable==1`（有效对够、峰尖锐），不会把空旷误判。

### 统一脱离（ST_DISENGAGE，比 BACKUP 更强）

- 三类卡死统一出口 = 持续倒车 `DISENGAGE_MS`（只倒车不转向，杜绝夹住还原地空转）。
- `disengCount >= DISENGAGE_MAX` 时倒车时长加倍（×2），反复被夹加强脱离。
- 完成 → `motorStop()`；`turnCount=0`；`enterCapRef()`（停车静态快扫重选向）。

### 修复 round-2（repaired by reviewer 意见）

1. **`verifyAfterTurn()` 的 `turnCount>=MAXTURN` 分支**：原"重置 `turnCount` 后 `enterCapRef()` 重选向"
   在"非全堵死但转后前方持续 `<FREESPACE`"（墙角/走廊）场景会无限"转向→验证失败→重转"打转。
   改为直接 `enterDisengage()`（内部已 `motorStop()`，不重置 `turnCount`），强制倒车脱离。
2. **`disengCount` 复位**：达到 `DISENGAGE_MAX` 后倒车时长永久加倍的问题，在"恢复正常前进"处复位：
   `verifyAfterTurn` 的 `front>=FREESPACE` 成功前进分支，以及 `ST_FORWARD` 正常直行前进分支，
   均置 `disengCount=0`（仅在真正恢复前进时复位，非每次）。
   → 使"反复被夹"按**连续计数**判断。

## 6. 关键可调参数

### 沿用 VFH 基础参数（不变）

| 参数 | 初值 | 说明 |
|---|---|---|
| `WALL_STOP` | 12 | 护栏急停距离 cm，越大越早停 |
| `TURN_DIST` | 25 | 接近→停车转向 cm，越大越早转向 |
| `SLOW_DIST` | 40 | 减速门限 cm |
| `HYST` | 6 | 迟滞带 cm |
| `FREESPACE` | 20 | 转向后验证可通行距离 cm |
| `MAXTURN` | 2 | 连续转向上限，超限进脱离 |
| `TURN_MS` | 350 | 单次原地开环转向时长 ms（随后闭环校准） |
| `BACKUP_MS` | 450 | 普通倒车脱离时长 ms（BACKUP 状态保留） |
| `SPD_HIGH/LOW/TURN` | 130/80/200 | 快行/减速/转向 PWM |

### 新增：轮廓匹配参数

| 参数 | 初值 | 说明 |
|---|---|---|
| `MATCH_SCAN_MS` | 40 | 停车静态快扫每档驻留 ms（比行进 `SERVO_DWELL` 快且静） |
| `MATCH_MIN_PAIRS` | 5 | 有效重叠对下限，少于则不可信（空旷回退开环） |
| `MATCH_MAX_PAIR_DIFF` | 3 | 每对平均允许差 cm（等价设计 `MATCH_ERR_MAX`=15） |
| `MATCH_MARGIN` | 2 | 最佳 vs 次佳误差最小差（峰尖锐度） |

### 新增：脱离参数

| 参数 | 初值 | 说明 |
|---|---|---|
| `DISENGAGE_MS` | 600 | 脱离模式倒车时长 ms（> BACKUP_MS，确保脱离被夹位） |
| `DISENGAGE_MAX` | 3 | 脱离触发上限，超限倒车时长加倍 |

### 调参建议

- **转向到位率偏低（匹配不可信回退多）**：放宽 `MATCH_MAX_PAIR_DIFF`（如 4~5）或
  降低 `MATCH_MIN_PAIRS`（如 4）；若环境空旷，接受回退开环属正常退化。
- **对称/走廊环境误校正**：增大 `MATCH_MARGIN`（如 3~4），让对称双峰更可能判定不可信回退。
- **仍原地打转**：减小 `MAXTURN`（如 1）加快进入脱离，或增大 `DISENGAGE_MS` 保证充分脱离。
- **物理卡死脱离不彻底**：增大 `DISENGAGE_MS` 或 `SPD_LOW`（倒车力度）。
- **前方稍开阔却频繁转向**：增大 `DEAD_ZONE` 或适当下调 `TURN_DIST`。

## 7. 已知退化假设（与设计/算法文档一致）

- 无里程计/陀螺仪/IMU：航向真实转角靠**点云轮廓匹配**实测（精度 ±1 扇区 = ±15°）；
  空旷/对称环境匹配不可信时**回退开环**（按 commanded 转角更新），不强制。
- 轮廓匹配仅用于"停车静止窗口"内的干净扫描；行进中扫描只刷新实时护栏。
- 物理卡死（无陀螺仪）由"command 转向但实测 bestShift≈0"检出，进入持续倒车脱离。
